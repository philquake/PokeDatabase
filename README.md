PokeDatabase
A lightweight Pokémon database application that provides structured Pokémon information for developers, students, and Pokémon enthusiasts. The project demonstrates how Pokémon data can be stored, queried, and managed through a simple application architecture.

Overview
PokeDatabase is designed to provide an organized way to access Pokémon data, including information such as Pokémon names, types, abilities, statistics, and other game-related attributes (depending on the available dataset).
The project serves as a foundation for:
* Pokémon lookup applications
* Database management practice
* API integration projects
* Educational database projects
* Full-stack development demonstrations

Features
* Search Pokémon by name
* View Pokémon information
* Structured database design
* Clean and maintainable project architecture
* Easy to extend with additional Pokémon data

Database
The project uses a structured Pokémon dataset that may include:
* Pokémon Name
* Pokédex Number
* Type(s)
* Height
* Weight
* Base Stats
* Abilities
* Evolutions
* Generation
